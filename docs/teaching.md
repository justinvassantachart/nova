# Teaching with web-ide

The public [instructor guide](https://github.com/justinvassantachart/web-ide/blob/main/docs/teaching.md)
is maintained in the web-ide repository. It covers the hosted IDE, lessons,
classroom workflow, tests, and storage behavior.

To use the component in your own course site, see
[Import IDE component](https://github.com/justinvassantachart/web-ide/blob/main/docs/import-ide-component.md).
